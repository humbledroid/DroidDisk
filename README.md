# DroidDisk

Your Android phone, right on your Mac. Browse it, move files both ways at any size, and clear space without losing anything you'd miss.

This repository hosts DroidDisk's releases. Learn more at [humbledroid.com/products/droiddisk](https://humbledroid.com/products/droiddisk/).

## Download

Get the newest version from [Releases](https://github.com/humbledroid/DroidDisk/releases/latest).

DroidDisk runs on Macs with Apple silicon.

## Before you start

1. Install Android Platform Tools. With Homebrew: `brew install android-platform-tools`
2. On your phone, open Settings, then Developer options, and turn on USB debugging.
3. Connect your phone and tap Allow when it asks.

## Opening it the first time

DroidDisk isn't from the App Store, so macOS checks with you once. Open DroidDisk and click Done when macOS says it can't verify it. Then open System Settings, go to Privacy & Security, and click Open Anyway next to DroidDisk.
